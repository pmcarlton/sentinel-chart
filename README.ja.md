# 日本の感染症発生動向調査：定点報告

[English](README.md)

このアプリは、日本の感染症の週ごとの報告を表示します。国立健康危機管理研究機構（JIHS）の速報データを使っています。最大2つの疾患について、全国の推移や都道府県ごとの状況を確認できます。

**このアプリは非公式の集計です。** 公式の数値や更新情報は、[JIHSの感染症発生動向調査サイト](https://id-info.jihs.go.jp/surveillance/idwr/index.html)で確認してください。速報値は後から修正されることがあります。

## アプリを起動する

Python 3、インターネット接続、このフォルダーへの書き込み権限が必要です。プロジェクトのフォルダーで次のコマンドを実行してください。

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

Streamlitが表示するローカルアドレスをブラウザーで開いてください。

初回起動時は、`data/` のCSVファイルをローカルデータベースに読み込みます。少し時間がかかることがあります。アプリを終了するには、ターミナルで `Ctrl+C` を押してください。

## アプリを使う

1. サイドバーで言語を選びます。
2. **疾患1**で疾患を選びます。**疾患2**で2つ目を選ぶか、**なし**を選びます。
3. 報告数または定点当たり報告数を選びます。定点とは、患者数を報告する医療機関です。報告数は日本全体の患者数ではありません。
4. スライダーで週を選ぶか、推移グラフ上の点を選びます。
5. 表で都道府県を選ぶと、地図が拡大します。リセットボタンで全国表示に戻せます。

**データの解釈**にポインターを合わせると、疾患を比較するときの注意点や報告方法の変更を確認できます。選択した週の出典がある場合は、サイドバーから開けます。

## 地図の見方

疾患が1つの場合は、値が高いほど色が濃くなります。2つの場合は、1つ目の疾患がマゼンタ、2つ目が緑で表示されます。両方がゼロなら白、両方が高い場合は濃い灰色です。黄色は値が欠けていることを示します。

色の濃さは、選択した指標について、保存済みデータの都道府県別の最大値を基準にしています。そのため、2つの色は、それぞれの疾患の最大値に対する水準を示します。患者数を直接比較するものではありません。原資料の `-` は欠測として扱います。

疾患によって、報告する医療機関の種類や対象患者が異なるため、比較には注意が必要です。また、インフルエンザの報告定点は2025年第15週に変更されました。その前後の比較にも注意してください。

## データと更新

- `data/` には出典のCSVファイルが入っています。アプリは新しくダウンロードしたファイルをここに保存します。直近の週を更新すると、既存のファイルを置き換えることがあります。
- `japan_surveillance_verified.db` は、これらのファイルから作成するローカルのSQLiteデータベースです。Gitでは管理しません。
- アプリを開くと、6時間に1回を上限として更新を確認します。開いたままの画面でも定期的に確認します。新しく終了した週を探し、保存済みの直近3週も再取得します。アプリを停止している間は確認せず、次に開いたときに確認します。
- サイドバーに自動確認の日時とダウンロードエラーを表示します。全履歴バックフィルのボタンでは、過去の欠けている週の取得と直近データの更新ができます。
- 地図の境界データは別にダウンロードします。保存済みの境界データがない場合、地図の表示にはインターネット接続が必要です。

更新に失敗した場合は、接続を確認し、時間を置いてバックフィルボタンを試してください。データが表示されない場合は、`data/` に出典のCSVファイルがあることと、プロジェクトのフォルダーに書き込めることを確認してください。
